## 二、核心命令

### 1. 路径相关

| 命令 | 作用 |
|---|---|
| pwd | 显示当前所在路径 |
| cd 目录 | 进入目录 |
| cd .. | 返回上一级 |
| cd /d/Learn_code | 绝对路径进入 |
| cd docs | 相对路径进入 |

### 2. 查看目录

| 命令 | 作用 |
|---|---|
| ls | 列出当前目录文件 |
| ls -l | 详细信息 |
| ls -a | 显示隐藏文件 |
| ls -R | 递归列出所有子目录 |

### 3. 创建目录

| 命令 | 作用 |
|---|---|
| mkdir 目录 | 新建文件夹 |
| mkdir a b c | 一次建多个 |
| mkdir -p a/b/c | 一次建多层 |

### 4. 写文件与查看

| 命令 | 作用 |
|---|---|
| echo "内容" > 文件 | 覆盖写入 |
| echo "内容" >> 文件 | 追加写入 |
| cat 文件 | 查看文件内容 |
| wc -l 文件 | 统计行数 |
| wc -l < 文件 | 只显示行数，不显示文件名 |

### 5. 复制与移动

| 命令 | 作用 |
|---|---|
| cp 源 目标 | 复制文件 |
| cp -r 源 目标 | 复制文件夹 |
| mv 旧 新 | 重命名或移动 |

### 6. 删除

| 命令 | 作用 |
|---|---|
| rm 文件 | 删除文件 |
| rmdir 空目录 | 删除空文件夹 |
| rm -r 目录 | 删除非空文件夹（危险，慎用） |

### 7. 查找与筛选

| 命令 | 作用 |
|---|---|
| find . -name "*.py" | 查找所有 .py 文件 |
| find . -type f | 查找所有文件 |
| grep 关键词 | 筛选包含关键词的行 |

### 8. 管道与重定向

| 符号 | 作用 |
|---|---|
| \| | 管道，把前一个命令结果交给后一个命令 |
| > | 覆盖写入文件 |
| >> | 追加写入文件 |
| < | 把文件内容作为输入 |

示例：

    ls -R | grep docs
    ls -R > notes/file_list.txt
    wc -l < docs/note.txt

## 三、踩坑记录

1. ls 打成了 1s：数字 1 不是字母 l
2. wc -l 打成了 wc -1：字母 l 不是数字 1
3. 复制文件夹必须加 -r，否则报错 -r not specified
4. find 的匹配要加通配符，"*.py" 不是 ".py"
5. mkdir -p 能建多层，不加 -p 会失败
6. 删空文件夹用 rmdir，删文件用 rm，别搞反
7. 文件夹名统一：test 是测试，text 是文本，别混
