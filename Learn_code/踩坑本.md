### 坑 2：纸条和盒子并排站着，中间没有 `+`

- **我干了什么**：`print(name 你好，你今年age岁)`
- **现象**：`SyntaxError: invalid syntax. Perhaps you forgot a comma?`
- **原因**：没有分隔符
- **下次怎么做**：任意两个东西之间加+

---

### 坑 3：引号外面出现了中文逗号 `，`

- **我干了什么**：在代码里（引号外面）用了中文标点
- **现象**：`SyntaxError: invalid character '，' (U+FF0C)`
- **原因**：格式错误
- **下次怎么做**：输入法切英文 / 认 U+ 开头的报错

---

### 坑 4：把「盒子名」也一起关进了引号里

- **我干了什么**：`print(' name 你好，你今年 age 岁')`
- **现象**：程序能跑，但屏幕上印出来的是字面的 **name** 和 **age** 两个词，不是盒子里的内容
- **原因**：相当于把盒子当成文字
- **下次怎么做**：盒子和文字之间加+

---

### 坑 5：给「命令」加了引号

- **我干了什么**：`print("int(your_age)"+1)`
- **现象**：`TypeError: can only concatenate str (not "int") to str`
- **原因**：""还是文字，文字+数字会有报错
- **下次怎么做**：引号只包文字，不包命令

---

### 坑 6：`input()` 拿回来的东西直接做算术

- **我干了什么**：`your_age = input("你今年几岁？")`，然后 `print(your_age + 1)`
- **现象**：`TypeError: can only concatenate str (not "int") to str`
- **原因**：input是文字
- **下次怎么做**：int(age)括号换成英文的

---

### 坑 7：把数字直接拼进句子里

- **我干了什么**：`print("你好，"+name+"你今年"+age+"岁")`
- **现象**：`TypeError: can only concatenate str (not "int") to str`
- **原因**：不能数字+文字
- **下次怎么做**：str()转化为文字，括号换成英文的
