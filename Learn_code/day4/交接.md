## 十、怎么"提前准备课件"（实操要点）

**背景**：学员的 VS Code 已经打开 `D:\Learn_code` 这个文件夹，所以**文件一建好他就直接能看见**，不用他自己新建。

### 方法：用 Python 脚本写文件，不要用 PowerShell 的写文件命令

**为什么**：这台机器的 PowerShell 处于 **ConstrainedLanguage 模式**，`Set-Content`、`New-Item`、`[math]::Round` 这类会报错。Python 不受这个限制：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
$py = @'
import pathlib
f = pathlib.Path(r"D:\Learn_code\day4\02_变量和输入.py")
f.write_text("...课件内容...", encoding="utf-8")
print("已写入:", f, f.stat().st_size, "字节")
'@
$tmp = Join-Path $env:TEMP 'setup.py'
Set-Content -Path $tmp -Value $py -Encoding UTF8    # 写临时文件这步可以
& 'D:\py\Python3\python.exe' $tmp                    # 但内容生成交给 Python
```

**写完立刻自己跑一遍验证**：

```powershell
& 'D:\py\Python3\python.exe' 'D:\Learn_code\day4\02_变量和输入.py'
```

**注意**：带 `input()` 的脚本会**卡住等输入**，没法直接验证。
解决办法：先只验证逻辑（把 `input()` 换成固定值跑一遍），或者干脆让学员自己跑。

### 其他已知的机器限制

| 限制 | 表现 | 应对 |
|---|---|---|
| PowerShell ConstrainedLanguage | `Set-Content`/`New-Item`/`[math]::*` 报错 | 改用 Python 脚本 |
| PowerShell 执行策略禁止 `.ps1` | `PSScriptRoot`/脚本无法加载 | 命令前加 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force` |
| 沙箱禁止启动 Git Bash | `bash.exe: NtCreateDirectoryObject ... 0xC0000022` | **不要用 bash 代跑命令**，让学员自己在终端敲，或改用 Python |
| 沙箱临时目录会被清掉 | `--temp is not an existing directory` | 让学员在终端跑 `mkdir -p /c/Users/马钧文/AppData/Local/Temp/dsh-XXXX` |
| 浏览器/Edge 无法在沙箱内启动 | `mojo platform_channel ... 拒绝访问` | 需要一次性 `danger-full-access` 批准（生成 PDF 时用） |

### 生成 PDF 的方法（Day3 用过，以后可能复用）

Markdown → HTML（自己写 Python 转换脚本）→ Edge 无头模式打印：

```powershell
& 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe' `
  --headless=new --disable-gpu --no-pdf-header-footer `
  --user-data-dir='D:\DSH\_build\edge-profile' `
  --print-to-pdf='输出路径.pdf' 'file:///HTML路径.html'
```

**注意 URL 里的中文要转成百分号编码**，否则打不开。
生成后**记得删掉 `edge-profile` 临时目录**（几 MB）。
